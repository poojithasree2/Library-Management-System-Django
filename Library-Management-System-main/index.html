About

Why This Project?

Traditional library management can involve considerable manual effort when maintaining book records, student information, issue records and fines.

This project provides a centralized web-based library management system that makes these operations easier to manage.

The application follows a Django Model-View-Template architecture and uses a relational database for storing application data.

The system is designed as an academic project to demonstrate practical skills in web development, database management, authentication and CRUD operations.

Features

Secure login and user management functionality for accessing the library system.

👨‍💼 Admin Interface

📚 Book Management

Create, update, delete and search library book records.

📕 Book Issue & Return

Manage book issue and return operations through the application.

💵 Fine Calculation

Track overdue books and calculate applicable fines based on the project's configured rules.

Search and find books efficiently from the library collection.
